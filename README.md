# Setback – Family Edition

A single-file web implementation of the Setback (Pitch) card game, playable offline (vs bots) and online (via Firebase). Features custom SVG card art, a responsive table layout, and a beautiful UI with Tailwind CSS.

## Features
- Play Setback (Pitch) with bots or online with friends
- Drag-and-drop or tap to play cards
- Custom SVG card art for all cards
- Responsive, visually appealing table layout
- No build step: just open `index.html` in your browser

## Getting Started
1. Clone the repo:
   ```sh
   git clone https://github.com/AudioInnovative/setback-family-edition.git
   ```
2. Open `index.html` in your browser (for offline play)
3. For online play, configure Firebase in the code (see comments)

## Project Structure
- `index.html` – Main game file (UI, logic, and styles)
- `setback_comprehensive_plan.md` – Full implementation plan
- `setback_rule_engine_spec.md` – Rule engine and data models
- `setback_master_gameplan.md` – Feature roadmap
- `setback_single_html_gameplan.md` – Single-file web build plan
